# Replication Project

## Paper

Ludwig et al. (2021), "Causal Effect of Children's Secondary
Education on Parental Health Outcomes: Findings from a Natural
Experiment in Botswana."

## Data

The project uses Botswana census data from IPUMS International.
The original data are not included in this repository.

## Method

The original paper uses Botswana's 1996 education reform as an
instrument for children's educational attainment. The analysis includes
ordinary least squares, intention-to-treat models, and two-stage least
squares instrumental-variable models.

## Files

- `analysis.do`: data cleaning and statistical analysis
- `descriptive_statistics.csv`: nonconfidential summary statistics
