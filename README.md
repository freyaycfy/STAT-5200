# STAT 5200 Replication and Research Project

This repository contains the replication project and original research
project for STAT 5200.

## Replication Project

We plan to replicate:

Ludwig, J. O., Davies, N. M., Bor, J., and De Neve, J.-W. (2021).
"Causal Effect of Children's Secondary Education on Parental Health
Outcomes: Findings from a Natural Experiment in Botswana."
BMJ Open, 11, e043247.

The replication uses Botswana census data from IPUMS International.

## Original Research Project

The original project examines the relationship between cognitive
function, dental-care utilization, and out-of-pocket dental spending
among older adults using the Health and Retirement Study.

## Data Availability

The HRS and IPUMS individual-level data are stored locally and are not
uploaded to GitHub because their data-use agreements restrict
redistribution.

The analysis code and nonconfidential summary results are included in
this repository.
