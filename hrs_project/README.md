# Original HRS Project

## Research Question

Is poorer cognitive function associated with lower dental-care
utilization and different levels of out-of-pocket dental spending
among older adults?

## Data

The project uses the RAND Health and Retirement Study files.
The respondent-level data are stored locally and are not included
in this repository.

## Planned Analysis

The analysis will include descriptive statistics, logistic regression
for dental-care utilization, and a two-part model for dental spending.

## Files

- `analysis.do`: data cleaning and statistical analysis
- `descriptive_statistics.csv`: nonconfidential summary statistics
